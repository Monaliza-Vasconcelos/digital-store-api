📦 API da Loja Digital (Django REST Framework)

Esta é uma API REST desenvolvida com Django e Django REST Framework, responsável por gerenciar o backend de uma loja virtual. Ela fornece autenticação de usuários, cadastro e gerenciamento de produtos, além de estrutura preparada para integração com um frontend em React.

🚀 Funcionalidades
🔐 Autenticação de usuários (login e registro)
👤 Sistema de usuários com JWT
📦 CRUD completo de produtos (criar, listar, atualizar e deletar)
🛒 Estrutura preparada para carrinho de compras (caso implementado)
🌐 API RESTful para consumo por frontend (React, mobile, etc.)
🗄️ Integração com banco de dados PostgreSQL em produção
🧰 Tecnologias utilizadas
Python
Django
Django REST Framework
Simple JWT (autenticação)
PostgreSQL
Render (deploy)
CORS Headers
🌍 Deploy

A API está hospedada na plataforma Render e pronta para consumo por aplicações frontend.

📌 Observações

Este projeto faz parte de um sistema full stack, sendo consumido por uma aplicação frontend desenvolvida em React.
