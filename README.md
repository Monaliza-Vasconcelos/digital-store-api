## 📦 API da Loja Digital

API REST desenvolvida com Django e Django REST Framework, responsável pelo backend de uma loja virtual. O projeto fornece autenticação de usuários, gerenciamento de produtos e estrutura pronta para integração com aplicações frontend modernas, como React.

---

## 🚀 Funcionalidades
🔐 Autenticação de usuários com JWT
👤 Cadastro e login de usuários
📦 CRUD completo de produtos (Create, Read, Update, Delete)
🌐 API RESTful para consumo por frontend e mobile
🗄️ Integração com banco de dados PostgreSQL
⚙️ Estrutura preparada para escalabilidade

---

## 🧰 Tecnologias utilizadas
Python
Django
Django REST Framework
Simple JWT
PostgreSQL
django-cors-headers
Render (deploy)

---

## 🌍 Deploy

API hospedada na plataforma Render, pronta para integração com frontend.

---

## 📌 Observações

Este projeto faz parte de um sistema full stack, sendo consumido por uma aplicação frontend desenvolvida em React, separando claramente backend e frontend para melhor organização e escalabilidade.
